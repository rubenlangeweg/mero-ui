# Mero UI · Component overview

Mero UI organizes its catalog into a core HTMX 4 runtime and optional component families. Start the local preview with `npm start` to browse all examples and variants.

## Verification

Every pull request runs automated checks across Chromium, Firefox, and WebKit covering keyboard workflows, HTMX 4 swaps, Alpine.js coexistence, focus continuity, and public API stability. See [Spacing standards and visual review](component-standards.md) and [Quality review and remaining work](quality-review.md).
